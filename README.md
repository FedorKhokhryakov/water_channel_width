# water_channel_width

Ширина ледового канала за кормой ледокола по кадрам кормовой камеры:
сегментация (U-Net) → горизонт и ориентация камеры → кромки канала → ширина в метрах.
Сервис для судна (Astra Linux, без интернета): следит за папкой с zip-архивами и пишет результаты.

Работа в процессе: репозиторий заполняется по частям.
